# «Напомни» — Android-приложение напоминаний (v1.1)

Точное напоминание о деле («Выпить таблетки в 15:00»), отложение на N минут (1–180),
раздел заметок, история + статистика, резервная копия, виджет и встроенная инструкция.
**Полностью без интернета** — в манифесте нет ни INTERNET, ни ACCESS_NETWORK_STATE.

Статус: **все этапы M1–M6 завершены**. Сборка `BUILD SUCCESSFUL`, тесты **30/30**.

Изменение v1.1: тёмная тема теперь реально применяется (переключатель сразу меняет оформление,
включая экран срабатывания), у виджета появилась тёмная раскладка.

## Что реализовано (по ТЗ v1.2)

- **Напоминания (FR-2)**: расписание — разово / ежедневно (1–6 раз в сутки) / по дням недели /
  каждые N дней; окончание «до даты» или «после K срабатываний» (EndMode).
- **Срабатывание (FR-3)**: тип для каждого напоминания — уведомление или «как будильник»
  (setAlarmClock, полноэкранный экран, bypass DND). Точное время (SCHEDULE_EXACT_ALARM).
- **Отложить (FR-5)**: настраиваемые пресеты кнопок (по умолчанию 5/15/30 мин, 1–180) +
  произвольный ввод 1–180 мин; без ограничения числа откладываний.
- **Пропуски (FR-4)**: окно «пропущено» — 60 мин (уведомление) / 30 мин (будильник);
  «Выполнено» работает и после окна → статус «выполнено с опозданием».
- **Заметки (FR-7)**: текст + чек-листы, 8 цветов, категории, поиск, закрепление, архив.
- **История и статистика (FR-6)**: история с фильтрами (статус/напоминание) и снимком названия
  удалённых; календарь с окраской дней и диалогом дня; «X из Y», серия дней (streak),
  недельные столбики; дисциплина в процентах; статистика по каждому напоминанию (7/30/90 дней).
- **Резервная копия (FR-10)**: экспорт/импорт JSON (schemaVersion=1) — напоминания, заметки,
  категории, история и настройки; импорт = полная замена данных с предупреждением и кнопкой
  «Сначала экспорт».
- **Виджет (FR-11)**: 3–4 ближайших срабатывания + кнопка «+» (сразу форма создания);
  обновляется при изменении данных, открытии приложения и раз в 15 минут (updatePeriodMillis).
- **Инструкция (FR-12)**: 10 глав простым языком, офлайн; в главах 5 и 10 — рабочие кнопки
  проверки разрешений; отдельный экран разрешений в «Настройках».
- **Разрешения (FR-9)**: онбординг при первом запуске (уведомления, точные будильники,
  полноэкранные, батарея Xiaomi) со скипом; баннер на главном экране; всё дублируется
  в «Настройках» → «Разрешения».
- **Звук (FR-8.2)**: выбор звука уведомлений и «будильника» отдельно (системный пикер);
  каналы пересоздаются при смене звука.
- **Темы (FR-8.1)**: светлая / тёмная / как в системе; выбор сразу меняет оформление всего
  приложения (включая экран срабатывания), виджет имеет тёмную раскладку для тёмного режима.

## Проверки

- Тесты: **30/30** — ScheduleCalculator (8), ReschedulePlanner (7), StatsCalculator (6),
  UpcomingSlots (5), Backup (4: round-trip JSON, сущности↔DTO, отказ от будущей схемы,
  игнор неизвестных полей).
- В манифесте **нет** `INTERNET` и `ACCESS_NETWORK_STATE` (сетевые права библиотеки WorkManager
  вырезаны `tools:node="remove"`).
- Релиз подписан (отладочным ключом — для ручной установки, магазины не используются).

## Сборка

```

export ANDROID_HOME=/home/user/.local/opt/android-sdk
export GRADLE_USER_HOME=/home/user/.local/opt/gradle-home
/home/user/.local/opt/gradle-8.9/bin/gradle test assembleDebug assembleRelease
```

Стек: Kotlin 2.0.21, Jetpack Compose (BOM 2024.10.01), MVVM, Room 2.6.1 (destructive v3),
