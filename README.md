# «Напомни» — Android-приложение напоминаний (v1.1.1)

Точное напоминание о деле («Выпить таблетки в 15:00»), отложение на N минут (1–180),
раздел заметок, история + статистика, резервная копия, виджет и встроенная инструкция.
**Полностью без интернета** — в манифесте нет ни INTERNET, ни ACCESS_NETWORK_STATE.

Статус: **все этапы M1–M6 завершены**; в v1.1.1 исправлена ошибка, из-за которой
уведомление о напоминании не приходило. Тесты (30 шт.) не менялись, но в песочнице,
где правился код, нет JDK и Android SDK — **сборку и тесты нужно прогнать заново** (см. «Сборка»).

Изменение v1.1: тёмная тема теперь реально применяется (переключатель сразу меняет оформление,
включая экран срабатывания), у виджета появилась тёмная раскладка.

## Что исправлено в v1.1.1

**Главная ошибка («напоминание ставится — уведомление не приходит»).**
При создании напоминания будильник планировался **до** записи в базу, то есть с `id = 0`
(`ReminderEditViewModel.save` игнорировал id, который вернул `upsert`). Приёмник
срабатывания отбрасывает такие будильники (`if (reminderId <= 0) return` в `AlarmReceiver`),
поэтому в назначенную минуту не происходило ничего. Вдобавок все новые напоминания
использовали один код запроса `PendingIntent` и перекрывали друг друга.
Теперь: будильник ставится по сохранённой записи, а `AlarmScheduler` не принимает
напоминания без id (пишет ошибку в лог).

Остальное из того же круга:

- **Импорт резервной копии**: восстановленные напоминания сразу получают будильники
  (раньше уведомления не приходили до перезапуска приложения), будильники прежних
  записей снимаются.
- **«Сиротские» будильники v1.1** (с `id = 0`) снимаются при запуске приложения,
  перезагрузке, смене времени/пояса и ежедневной сверкой WorkManager.
- **Разрешения**: кнопка «Поверх экрана блокировки» открывала экран доступа ко всем файлам —
  теперь открываются правильные системные экраны (уведомления, точные будильники,
  полноэкранные уведомления, батарея). Для диалога «Без ограничений батареи» добавлено
  разрешение `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` — без него системный экран не открывался.
- **Звук в «Настройках»**: системный пикер не возвращает наши extras, поэтому выбор
  («уведомления» / «будильник») терялся — теперь цель запоминается в состоянии экрана.
- **Предупреждение при сохранении**: если напоминание сохраняется без разрешения на
  уведомления, показывается диалог с кнопкой «Разрешить» (раньше — тишина в назначенный час).
- **«Настройки» → «Проверка уведомлений»**: кнопка «Показать тестовое уведомление» —
  быстрый способ убедиться, что разрешение, канал и звук работают. Глава 5 «Инструкции»
  дополнена этим способом проверки.

## APK (распространение — установка вручную)

⚠️ Лежащие в репозитории APK — это **старая сборка v1.1 с описанной ошибкой**.
Пересоберите приложение (см. «Сборка») и установите новый APK.

| Файл | Назначение |
|---|---|
| `app-release-v1.1.apk` (12.3 МБ) | Черновик релиза v1.1 (уведомления не приходят — не использовать) |
| `app-debug-v1.1.apk` (18.6 МБ) | Отладочная сборка v1.1 (то же) |

Имена файлов новых сборок: `app-release-v1.1.1.apk`, `app-debug-v1.1.1.apk`
(`versionCode = 3`, `versionName = "1.1.1"`).

Минимальная версия: Android 8.0 (API 26).

## Что реализовано (по ТЗ v1.2)

- **Напоминания (FR-2)**: расписание — разово / ежедневно (1–6 раз в сутки) / по дням недели /
  каждые N дней; окончание «до даты» или «после K срабатываний» (EndMode).
- **Срабатывание (FR-3)**: тип для каждого напоминания — уведомление или «как будильник»
  (setAlarmClock, полноэкранный экран, bypass DND). Точное время (SCHEDULE_EXACT_ALARM).
- **Отложить (FR-5)**: настраиваемые пресеты кнопок (по умолчанию 5/15/30 мин, 1–180) +
  произвольный ввод 1–180 мин; без ограничения числа откладываний.
- **Пропуски (FR-4)**: окно «пропущено» — 60 мин (уведомление) / 30 мин (будильник);
  «Выполнено» работает и после окна → статус «выполнено с опозданием».
- **Заметки (FR-7)**: текст + чек-листы, 8 цветов, категории, поиск, закрепление, архив.
- **История и статистика (FR-6)**: история с фильтрами (статус/напоминание) и снимком названия
  удалённых; календарь с окраской дней и диалогом дня; «X из Y», серия дней (streak),
  недельные столбики; дисциплина в процентах; статистика по каждому напоминанию (7/30/90 дней).
- **Резервная копия (FR-10)**: экспорт/импорт JSON (schemaVersion=1) — напоминания, заметки,
  категории, история и настройки; импорт = полная замена данных с предупреждением и кнопкой
  «Сначала экспорт».
- **Виджет (FR-11)**: 3–4 ближайших срабатывания + кнопка «+» (сразу форма создания);
  обновляется при изменении данных, открытии приложения и раз в 15 минут (updatePeriodMillis).
- **Инструкция (FR-12)**: 10 глав простым языком, офлайн; в главах 5 и 10 — рабочие кнопки
  проверки разрешений; отдельный экран разрешений в «Настройках».
- **Разрешения (FR-9)**: онбординг при первом запуске (уведомления, точные будильники,
  полноэкранные, батарея Xiaomi) со скипом; баннер на главном экране; всё дублируется
  в «Настройках» → «Разрешения».
- **Звук (FR-8.2)**: выбор звука уведомлений и «будильника» отдельно (системный пикер);
  каналы пересоздаются при смене звука.
- **Темы (FR-8.1)**: светлая / тёмная / как в системе; выбор сразу меняет оформление всего
  приложения (включая экран срабатывания), виджет имеет тёмную раскладку для тёмного режима.

## Проверки

- Тесты: **30/30** — ScheduleCalculator (8), ReschedulePlanner (7), StatsCalculator (6),
  UpcomingSlots (5), Backup (4: round-trip JSON, сущности↔DTO, отказ от будущей схемы,
  игнор неизвестных полей). В v1.1.1 состав тестов не менялся; в песочнице правок нет
  JDK/Android SDK, поэтому прогон нужно сделать у себя (`gradle test`).
- В манифесте **нет** `INTERNET` и `ACCESS_NETWORK_STATE` (сетевые права библиотеки WorkManager
  вырезаны `tools:node="remove"`). Добавлено только `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` —
  иначе системный диалог «не ограничивать работу в фоне» не открывается.
- Релиз подписан (отладочным ключом — для ручной установки, магазины не используются).
- Быстрая ручная проверка после установки: «Настройки» → «Проверка уведомлений» →
  «Показать тестовое уведомление»; затем создать напоминание на 2 минуты вперёд
  и подождать (можно свернуть приложение).

## Если уведомление всё равно не приходит

1. «Настройки» → «Разрешения»: все четыре пункта должны быть зелёными (уведомления —
   обязательно).
2. «Настройки» → «Проверка уведомлений» → «Показать тестовое уведомление»: если плашки нет,
   показ уведомлений запрещён системой (или включён режим «Не беспокоить»).
3. Убедитесь, что у напоминания включён переключатель «Активно» и время ещё не прошло.
4. На Xiaomi/Huawei/Samsung разрешите приложению автозапуск и работу в фоне.

## Сборка

```
export JAVA_HOME=/home/user/.local/opt/jdk17
export ANDROID_HOME=/home/user/.local/opt/android-sdk
export GRADLE_USER_HOME=/home/user/.local/opt/gradle-home
/home/user/.local/opt/gradle-8.9/bin/gradle test assembleDebug assembleRelease
```

Инструменты ставятся скриптом `tools/setup_android.sh` (JDK 17, gradle-8.9, Android SDK 35
в `/home/user/.local/opt`). Каталог `/home/user/.local/opt` исключён из снапшотов рабочей
области, поэтому после «переезда» воркспейса инструменты нужно поставить заново.

Готовый APK — в `app/build/outputs/apk/` (переименуйте в `app-release-v1.1.1.apk`
и обновите таблицу APK выше).

Стек: Kotlin 2.0.21, Jetpack Compose (BOM 2024.10.01), MVVM, Room 2.6.1 (destructive v3),
DataStore, WorkManager 2.9.1 (ежедневная страховка перепланирования), AlarmManager
(setAlarmClock / setExactAndAllowWhileIdle), java.time, kotlinx-serialization-json 1.7.3.
Инструменты: gradle-8.9, AGP 8.7.3, Temurin JDK 17, Android SDK 35.

## Структура

`app/src/main/java/ru/napomni/app/` — `data/` (model, db, repository, settings, alarm, notify),
`domain/` (ScheduleCalculator, ReschedulePlanner, StatsCalculator, UpcomingSlots, Format, Limits,
Permissions, backup/BackupManager+BackupModels), `receiver/`, `work/`, `ui/` (reminders, notes,
stats, settings, help, onboarding, widget, action, components, theme).
