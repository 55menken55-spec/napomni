# Техническое задание
## Мобильное приложение «Напомни» (рабочее название)
**Напоминания + заметки, полностью офлайн, Android**

| | |
|---|---|
| Версия документа | 1.2 (дополнено: встроенная инструкция) |
| Дата | 22.09.2026 |
| Платформа | Android 8.0 (API 26) и выше |
| Распространение | Установка APK вручную (для себя / близких) |
| Язык интерфейса | Русский (en — возможен позже, вне v1) |

---

## 1. Назначение продукта

Приложение для людей, которым нужно **не забыть о конкретных действиях в конкретное время** (выпить лекарство, позвонить, полить цветы и т.п.), и **вести личные заметки** (в т.ч. списки дел).

Опорный сценарий:
> Человек записывает: «Выпить таблетки в 15:00 после приёма пищи». В 15:00 телефон громко напоминает об этом. Человек откладывает напоминание на нужное число минут или отмечает «Выполнено». Всё это работает **без интернета**, даже в самолёте.

**Жёсткое требование № 1: полная работа офлайн.**
Приложение не содержит разрешения `INTERNET` в манифесте — физически не может передавать данные наружу. Все данные хранятся только на устройстве.

---

## 2. Технический стек (рекомендация)

| Слой | Технология | Почему |
|---|---|---|
| Язык | Kotlin | Стандарт Android, корутины/Flow |
| UI | Jetpack Compose + Material 3 | Современный стек, меньше кода, тёмная тема из коробки |
| Архитектура | MVVM (ViewModel + StateFlow) | Просто, тестируемо |
| БД | Room (SQLite) | Надёжное локальное хранилище |
| Настройки | DataStore (Preferences) | Замена SharedPreferences |
| Планировщик | `AlarmManager` (`setAlarmClock`, `setExactAndAllowWhileIdle`) + `BroadcastReceiver` | Единственный способ **точно** сработать в нужную минуту, обходя Doze |
| Страховка | WorkManager (раз в сутки сверка расписания с БД) | Подстраховка от «убитых» будильников |
| Время | `java.time` (LocalDate/LocalTime/ZoneId) | API 26+, встроено |
| DI | Простой AppContainer (без Hilt) | Меньше магии для приложения такого размера |
| Сборка | Gradle (Kotlin DSL), minSdk 26, targetSdk 35 | Один универсальный APK |

Не используется: интернет, облако, аккаунты, сторонние SDK (аналитика/реклама — отсутствуют принципиально).

---

## 3. Структура приложения (экраны)

Нижняя навигация, 4 вкладки:

1. **Напоминания** — «Сегодня» (что предстоит/просрочено сегодня) + список всех активных напоминаний.
2. **Заметки** — список заметок с закреплёнными сверху, поиском и фильтром по категориям.
3. **Статистика** — календарь выполнения + сводки.
4. **Настройки** — пресеты отложения, звук/вибрация, тема, режим «будильник», разрешения.

Отдельные экраны:
5. **Создание/редактирование напоминания** (форма, см. FR-1).
6. **Редактор заметки** (текст + чек-лист, см. FR-7).
7. **Экран срабатывания (режим «будильник»)** — поверх блокировки, см. FR-3.
8. **Диалог «Отложить на N минут»** — произвольный ввод, см. FR-4.
9. **Онбординг при первом запуске** — запрос разрешений с объяснениями, см. FR-9.

## 4. Функциональные требования

### FR-1. Напоминания: создание, редактирование, удаление

**FR-1.1** Форма напоминания содержит:
- **Заголовок** (обязательно, до 120 символов) — напр. «Выпить таблетки».
- **Текст-детали** (необязательно) — напр. «…после приёма пищи».
- **Расписание** (тип + время/даты, см. FR-2).
- **Важность**: «Уведомление» или «Как будильник» (см. FR-3).
- **Категория** (необязательно, общая с заметками) и **цвет-метка** (палитра из 8 цветов).
- **Окончание** (см. FR-2.5).

**FR-1.2** Доступны действия: создать, редактировать, включить/выключить (пауза без удаления), удалить. Удаление — с подтверждением; при удалении отменяются все запланированные срабатывания.

**FR-1.3** Список напоминаний показывает: заголовок, краткое расписание («Ежедневно 9:00, 15:00»), цвет-метку, ближайшее срабатывание, состояние вкл/выкл.

**FR-1.4** Экран «Сегодня» показывает срабатывания текущего дня таймлайном со статусами: предстоит / выполнено / отложено до HH:MM / пропущено. Просроченные — сверху, красным.

### FR-2. Расписание (гибкие повторы)

Поддерживаемые типы (детально, чтобы не расходиться при реализации):

| Тип | Параметры | Пример |
|---|---|---|
| **Разовое** | Дата + время | «Сегодня в 15:00» |
| **Ежедневно** | Одно или несколько времени суток | «Каждый день в 9:00, 15:00, 21:00» |
| **По дням недели** | Набор дней + одно или несколько времени | «Пн, Ср, Пт в 10:00» |
| **Каждые N дней** | N (2–365) + дата начала + одно или несколько времени | «Каждые 3 дня в 20:00» |

**FR-2.1** Несколько времени суток — до 6 на одно напоминание (для «три раза в день» по таблеткам).

**FR-2.2** Валидация: разовое в прошлом — запрещено (подсказка «выберите будущее время»). Для повторяющихся время, уже прошедшее сегодня, просто переносит первое срабатывание на завтра/следующий по расписанию день.

**FR-2.3** Расписание считается по **локальному времени устройства** (wall-clock): при переводе часов срабатывания остаются на «то же настенное время» (15:00 остаётся 15:00).

**FR-2.4** При смене даты/времени/часового пояса на устройстве все будильники пересчитываются (приёмники `TIME_SET`, `TIMEZONE_CHANGED`).

**FR-2.5** Окончание расписание (опционально): «без окончания» / «до даты» / «после K срабатываний» (для курса лекарств «30 дней»). После окончания напоминание автоматически выключается и попадает в архив.

**FR-2.6 (вне v1, бэклог):** интервал «каждые N часов», цепочки «до еды / после еды», шаблоны.

### FR-3. Срабатывание: уведомления и режим «будильник»

**FR-3.1 Тип «Уведомление»** (важность по умолчанию):
- Всплывающее уведомление (`heads-up`) со звуком и вибрацией в назначенную минуту.
- Текст: заголовок + детали.
- Кнопки действий: **«Выполнено»**, **«Отложить 15»**, **«Отложить 30»** (два первых пресета из настроек, см. FR-4).
- Тап по уведомлению → экран напоминания с кнопками: «Выполнено», пресеты отложения, **«Другой интервал…»** (произвольный ввод, см. FR-4).
- Уведомление остаётся в шторке до действия пользователя.

**FR-3.2 Тип «Как будильник»** (для критичных дел, напр. лекарства):
- **Полноэкранный экран поверх экрана блокировки** (`USE_FULL_SCREEN_INTENT`, `SHOW_WHEN_LOCKED`), даже если телефон заблокирован.
- Громкий сигнал (выбранный звук) **повторяется с вибрацией**, пока пользователь не нажмёт кнопку.
- Кнопки большими: **«Выполнено»**, **«Отложить…»** (открывает выбор интервала).
- **Автостоп звука** через 2 минуты (настраивается 30 сек–5 мин) — телефон не будет орать вечно; экран и уведомление остаются.
- Если за 30 минут (настраивается 5–120) не было действия → срабатывание помечается «пропущено», экран закрывается, запись видна красным в «Сегодня».

**FR-3.3** Точность: срабатывание в **назначенную секунду**, включая Doze (используется `setAlarmClock` для режима «будильник», `setExactAndAllowWhileIdle` для уведомлений).

**FR-3.4** Если в одно время срабатывает несколько напоминаний — группируются в одно уведомление-группу («2 напоминания»), режим «будильник» показывается поверх (по одному экрану, очередь).

**FR-3.5** Каналы уведомлений (пользователь может настроить в системе): «Напоминания», «Важные (будильник)», «Служебные (пропущенные)».

### FR-4. Отложение (snooze)

**FR-4.1** Быстрые пресеты — в настройках задаётся список (по умолчанию **5, 15, 30** минут; от 1 до 4 значений, каждое 1–180 минут). Два первых пресета выводятся кнопками прямо в уведомлении.

**FR-4.2** Произвольный ввод: пункт **«Другой интервал…»** → диалог с числовым полем (1–180 минут) и кнопкой «Отложить». Доступен и из уведомления (тап), и с экрана «будильника».

**FR-4.3** Отложенное срабатывание планируется точно так же, как обычное (точный будильник).

**FR-4.4** Отложение влияет **только на текущее срабатывание**, не меняет расписание. Счётчик отложений для этого срабатывания хранится (виден в истории).

**FR-4.5** Если время отложения попадает на следующее срабатывание того же напоминания — разрешаем, оба события останутся в шторке (без «умного» слияния в v1).

**FR-4.6** «Выполнено» можно нажать в любой момент (в том числе из шторки, с экрана «будильник», из «Сегодня» и из истории) — срабатывание закрывается.

### FR-5. Статусы срабатываний

Каждое срабатывание (occurrence) имеет статус:
- **Предстоит** — запланировано.
- **Отложено** — перенесено (с указанием до какого времени и сколько раз).
- **Выполнено** — нажато «Выполнено» (время действия пишется в историю).
- **Пропущено** — не было действия в течение окна (см. FR-3.2; для типа «Уведомление» окно — 60 минут, настраивается).
- **Пропущено пользователем** — действие «Пропустить» (доступно в тапе по уведомлению и в «Сегодня»).

**FR-5.1** Настройка «Повторить сигнал для пропущенных» (по умолчанию выкл.): одно повторное уведомление через N минут (по умолчанию 15).

**FR-5.2** «Выполнено с опозданием»: кнопка «Выполнено» доступна и **после** окна «пропущено» (из шторки, «Сегодня» или истории) — статус меняется на «Выполнено (с опозданием)», в статистике считается выполненным. Фактическое время действия пишется в историю.

**FR-5.3** Окно «пропущено» по умолчанию: **60 минут** для типа «Уведомление», **30 минут** для режима «Будильник» (настраивается 5–120).

### FR-6. История и статистика

**FR-6.1 История** — хранится для всех срабатываний (даже удалённых напоминаний — данные статистики сохраняются): дата/время, напоминание, статус, число отложений. Фильтры: по напоминанию, по статусу, по периоду.

**FR-6.2 Календарь выполнения** (экран «Статистика»):
- Месячный календарь, каждый день окрашен: **зелёный** — все срабатывания выполнены, **жёлтый** — частично, **красный** — были пропуски, **серый** — не было срабатываний.
- Тап по дню → список срабатываний этого дня.

**FR-6.3 Сводка по напоминанию** (тап по напоминанию в «Статистике»):
- «Выполнено X из Y» за 7 / 30 / 90 дней, процент выполнения.
- Текущая серия (streak): «12 дней подряд без пропусков».
- Мини-график по неделям.

**FR-6.4 Сводка общая за период:** сколько всего срабатываний, выполнено / отложено / пропущено, процент дисциплины.

### FR-7. Заметки

**FR-7.1** Заметка содержит: **заголовок**, **текст**, **чек-лист** (можно совмещать со свободным текстом: текст и пункты идут блоками), **цвет** (палитра из 8), **категорию**, **закрепление**, даты создания/изменения.

**FR-7.2 Чек-лист:** добавить пункт, отметить выполнение (галочка + зачёркивание), редактировать текст, удалить, перемещать перетаскиванием (long-press drag). Выполненные пункты можно сворачивать.

**FR-7.3 Поиск** — по заголовку, тексту и пунктам чек-листа; мгновенный, локальный. Плюс фильтр по категории и «только закреплённые».

**FR-7.4 Закреплённые заметки** — вверху списка сеткой 2 колонки.

**FR-7.5** Жесты списка: свайп — архивировать; долгое нажатие — режим выбора (удалить, закрепить, изменить категорию/цвет). Архив доступен из меню.

**FR-7.6 Категории:** пользователь создаёт именованные категории с цветом (например «Лекарства», «Дом», «Работа»); общие для заметок и напоминаний. Удаление категории не удаляет записи.

**FR-7.7 (вне v1, бэклог):** связь «заметка ↔ напоминание», вложения/фото, Markdown.

### FR-8. Настройки

1. **Пресеты отложения** (см. FR-4.1).
2. **Звук и вибрация:** выбор системного звука для «Уведомлений» и для режима «Будильник» (могут отличаться), громкость по системной мультимедиа/будильнику, вкл/выкл вибрацию.
3. **Режим «будильник»:** длительность автостопа звука (30 сек–5 мин, по умолчанию 2 мин), окно «пропущено» (5–120 мин, по умолчанию 30).
4. **Пропущенные:** повтор сигнала вкл/выкл, интервал (по умолчанию 15 мин).
5. **Тема:** светлая / тёмная / как в системе.
6. **Разрешения и «здоровье»:** экран-проверка: разрешены ли уведомления, точные будильники, полноэкранные уведомления, снята ли оптимизация батареи — с кнопками-ссылками в системные настройки.
7. **О приложении:** версия, «данные не покидают устройство».
8. **Резервная копия:** «Сохранить копию данных» и «Восстановить из файла» (см. FR-10).
9. **Инструкция:** встроенное подробное руководство пользователя (см. FR-12).

### FR-9. Надёжность и системная интеграция

**FR-9.1** Все будильники восстанавливаются после **перезагрузки** (`BOOT_COMPLETED`) — расписание читается из БД, всё перепланируется.

**FR-9.2** Пересчёт при смене времени/даты/часового пояса (см. FR-2.4).

**FR-9.3** Ежесуточная сверка WorkManager: сравнить запланированные будильники с БД, дозапланировать недостающие (страховка от агрессивных прошивок).

**FR-9.4 Онбординг (первый запуск), по шагам с объяснением «зачем»:**
1. Разрешение на уведомления (`POST_NOTIFICATIONS`, Android 13+).
2. Разрешение на точные будильники (`SCHEDULE_EXACT_ALARM`, Android 12+).
3. Разрешение на полноэкранные уведомления (`USE_FULL_SCREEN_INTENT`) — для режима «будильник».
4. Отключение оптимизации батареи для приложения (`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`) — **особенно важно для Xiaomi/Redmi, Huawei, Honor, Samsung**; без этого прошивка может «убить» приложение и напоминания не сработают.
Всё можно пропустить; невыданные разрешения потом подсвечиваются на экране «Разрешения» и баннером на главном экране.

**FR-9.5** Повторный запрос критичных разрешений — только по инициативе пользователя (без «надоедания»).

### FR-10. Экспорт и импорт данных (резервная копия)

**FR-10.1** «Сохранить копию данных» (экран «Настройки» → «Резервная копия»): формируется **один JSON-файл** со всеми заметками, напоминаниями, категориями, историей и настройками. Сохранение — через системный выбор места (SAF, `ACTION_CREATE_DOCUMENT`): **без** запроса разрешений на файлы.

**FR-10.2** «Восстановить из файла»: чтение JSON через `ACTION_OPEN_DOCUMENT`, полная проверка формата перед импортом.

**FR-10.3** Политика импорта (v1): **полная замена текущих данных** с предупреждением («Текущие данные будут заменены. Если нужна копия — сначала сохраните её») и кнопкой «Сначала сделать экспорт». Слияние — вне v1 (бэклог).

**FR-10.4** В файле указывается `schemaVersion` — для совместимости формата в будущих версиях.

### FR-11. Виджет рабочего стола

**FR-11.1** Виджет (Glance / App Widget) размером 4×2 и больше: список **3–4 ближайших активных срабатываний** (цвет-метка, время, заголовок) + кнопка **«+»** (быстрое создание напоминания).

**FR-11.2** Тап по строке → приложение открывается на вкладке «Напоминания» с подсветкой выбранного. Тап «+» → форма создания напоминания.

**FR-11.3** Обновление: при изменении данных, при открытии приложения и таймером раз в 15 минут (строки с прошедшим временем заменяются следующими по расписанию). Пустое состояние: «Напоминаний нет».

**FR-11.4** Виджет работает без интернета и не требует разрешений.

### FR-12. Встроенная инструкция (руководство пользователя)

**FR-12.1** Раздел «Настройки» → **«Инструкция»**: подробное руководство простым разговорным языком. Контент **встроен в приложение** (файл в ресурсах) — работает офлайн и обновляется только вместе с приложением.

**FR-12.2** Форма подачи: оглавление из 10 глав; внутри главы — короткие пошаговые действия («1. Нажми… 2. Выбери…») крупным читаемым шрифтом, с иллюстрациями-скриншотами интерфейса (добавляются на полировке, M6). Состав глав:

1. **Что умеет приложение** — обзор на один экран.
2. **Как создать напоминание** — пошагово от кнопки «+» до первого срабатывания.
3. **Повторы** — ежедневно, по дням недели, каждые N дней; готовые примеры («таблетки 3 раза в день», «Пн, Ср, Пт в 10:00», «курс 30 дней»).
4. **Когда напоминание сработало** — кнопки «Выполнено», «Отложить», «Другой интервал»; чем «Уведомление» отличается от «Будильника»; что значит «пропущено» и «выполнено с опозданием».
5. **Заметки и списки дел** — создание, галочки, цвета, категории, поиск, закрепление, архив.
6. **Статистика** — как читать календарь (зелёный / жёлтый / красный), что такое «серия дней».
7. **Виджет на рабочем столе** — как добавить и как им пользоваться.
8. **Резервная копия** — как сохранить данные в файл и восстановить из него.
9. **Если напоминания не срабатывают** — проверка разрешений, батарея и режим экономии, особенности Xiaomi/Redmi, Huawei, Honor, Samsung; из главы — прямые кнопки-ссылки на экран «Разрешения» и в нужные системные настройки.
10. **Приватность** — данные хранятся только в телефоне, интернет приложению не нужен.

**FR-12.3** Текст уважает системный масштаб шрифта; приоритет — крупный шрифт и простые фразы (аудитория включает пожилых людей). Доступ также с последнего шага онбординга («Открыть инструкцию»).

## 5. Модель данных (кратко)

- **Reminder**: id, title, details, scheduleType (ONCE / DAILY / WEEKLY / INTERVAL_DAYS), times[], weekdays[], intervalDays, startDate, endDate?, maxOccurrences?, importance (NOTIFICATION / ALARM), categoryId?, color, enabled, createdAt, updatedAt.
- **Occurrence** (история): id, reminderId (связь сохраняется после удаления напоминания), scheduledAt, status (PENDING / SNOOZED / DONE / MISSED / SKIPPED), completedAt?, snoozeCount, snoozedUntil?.
- **Note**: id, title, blocks[] (TEXT / CHECK_ITEM с order и done), color, categoryId?, pinned, archived, createdAt, updatedAt.
- **Category**: id, name, color.
- **Settings** (DataStore): пресеты отложения, звуки, вибрация, тайминги режима «будильник», тема, политика пропущенных.

Экспорт/импорт (FR-10) сериализует все сущности выше в единый JSON с полем `schemaVersion`.

## 6. Разрешения Android (полный список)

| Разрешение | Зачем |
|---|---|
| `POST_NOTIFICATIONS` | Уведомления (Android 13+) |
| `SCHEDULE_EXACT_ALARM` | Точные будильники (Android 12+) |
| `USE_FULL_SCREEN_INTENT` | Экран «будильник» поверх блокировки |
| `RECEIVE_BOOT_COMPLETED` | Восстановление расписания после перезагрузки |
| `VIBRATE` | Вибрация при срабатывании |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Защита от «убийства» прошивкой (Xiaomi и др.) |
| `WAKE_LOCK` (normal) | Удержание CPU при срабатывании |

**Отсутствуют намеренно:** `INTERNET`, доступ к файлам, контактам, местоположению и прочему.

## 7. Нефункциональные требования

- **Офлайн:** 100% функций без сети; в манифесте нет `INTERNET`.
- **Приватность:** данные только на устройстве (Room), без аналитики и трекеров.
- **Надёжность:** срабатывание в назначенную минуту; восстановление после перезагрузки и в Doze (критерий приёмки — тесты в разделе 9).
- **Производительность:** холодный старт < 1.5 с; списки на 1000+ заметок и 500+ напоминаний без тормозов (пагинация/ленивые списки).
- **Доступность:** контрастность Material 3, подписи для TalkBack, размеры тап-целей ≥ 48 dp.
- **Батарея:** без фоновых циклов и поллинга; только точные будильники + разовая страховка WorkManager/сутки.

## 8. Граничные случаи (обязательны к обработке)

1. Время разового напоминания в прошлом → блокировка с подсказкой (FR-2.2).
2. Перевод часов / смена часового пояса → пересчёт по «настенному» времени (FR-2.3–2.4).
3. Несколько срабатываний в одну минуту → группа уведомлений / очередь экранов (FR-3.4).
4. Отложение за границу следующего срабатывания → разрешено (FR-4.5).
5. Удаление/выключение напоминания → отмена будильников; история сохраняется.
6. Приложение убито / телефон перезагружен в момент до срабатывания → сработает (BOOT_COMPLETED + страховка WorkManager).
7. Пользователь отключил уведомления или отозвал точные будильники → баннер предупреждения + переход в настройки (FR-8.6).
8. Экран «будильник» при включённом DND → звук по каналу «Будильник» (системные будильники игнорируют DND); пользователь предупреждён в онбординге.
9. Разрядился телефон в тишине и включился позже времени срабатывания → при включении срабатывания с временем в прошлом помечаются «пропущено» (не спамим уведомлениями); опциональный повтор — по настройке FR-5.1.
10. Облачные бэкапы Android (Auto Backup): **выключены** или экспортируют только настройки — данные заметок/истории не утекают в Google (решение v1: авто-бэкап выключен).

## 9. Критерии приёмки (чек-лист)

- [ ] Создано напоминание «Выпить таблетки, ежедневно 15:00, важность — будильник» → в 15:00 экран поверх блокировки со звуком, кнопки «Выполнено» / «Отложить…».
- [ ] «Отложить → 7 минут» (произвольный ввод) → повтор ровно через 7 минут.
- [ ] Пресеты отложения в уведомлении совпадают с настройками.
- [ ] Напоминание «каждые 3 дня» и «Пн, Ср, Пт» срабатывают по расписанию.
- [ ] Всё работает в авиарежиме / без SIM / без Wi-Fi.
- [ ] Перезагрузка телефона за 5 минут до срабатывания → срабатывание происходит.
- [ ] 24 часа в Doze (экран выключен) → точное срабатывание.
- [ ] Перевод часов на ±1 час → напоминание остаётся на «настенном» 15:00.
- [ ] Заметка с чек-листом: создание, галочки, drag-reorder, поиск по пункту чек-листа, закрепление, фильтр по категории.
- [ ] Статистика: календарь окрашен корректно; «выполнено X из Y» за 30 дней сходится с историей.
- [ ] В манифесте отсутствует разрешение `INTERNET`.
- [ ] Удалённое напоминание: будильники отменены, история сохранена.
- [ ] Не отреагировал на уведомление 60 минут → статус «пропущено»; нажал «Выполнено» позже → «выполнено с опозданием», в статистике считается выполненным.
- [ ] Экспорт создаёт файл; после «Восстановить из файла» на чистом телефоне заметки, напоминания и история восстановлены полностью.
- [ ] Виджет: показывает 3–4 ближайших напоминания, обновляется после изменений; кнопка «+» открывает создание напоминания.
- [ ] Инструкция открывается из «Настроек» и с онбординга: все 10 глав доступны офлайн, из главы «не срабатывают» работают переходы к разрешениям и системным настройкам.
